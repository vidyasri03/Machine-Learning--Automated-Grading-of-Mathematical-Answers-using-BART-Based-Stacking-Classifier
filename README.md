# Machine-Learning--Automated-Grading-of-Mathematical-Answers-using-BART-Based-Stacking-Classifier
Developed a tri-class NLP-based system using BART embeddings and stacking ensemble models to evaluate student responses. Performed cross-validation and hyperparameter tuning, achieving 97.89% CV accuracy and 91.43% test accuracy, with SHAP-based model interpretability.
